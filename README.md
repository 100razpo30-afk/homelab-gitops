# Homelab GitOps

Этот репозиторий хранит желаемое состояние Kubernetes-кластера `homelab`.
Argo CD должен читать манифесты отсюда и синхронизировать их с кластером.

Подробности безопасного первого подключения находятся в [MIGRATION.md](MIGRATION.md).

## Структура

```text
bootstrap/argocd/       Первичная настройка Argo CD
clusters/homelab/       Состав приложений конкретного кластера
infrastructure/         Общие контроллеры и кластерная инфраструктура
applications/           Ресурсы прикладных систем
secrets/                Правила работы с секретами; только шифрованные данные
```

## Источники текущей конфигурации

- `applications/contest` перенесён из `contest/k8s`;
- `applications/kontent` перенесён из `kontent/k8s`;
- общие MetalLB, Gateway API, cert-manager и monitoring вынесены в `infrastructure`;
- исходные файлы в репозиториях приложений пока сохранены для безопасной миграции.

## Порядок первой синхронизации

1. Создать удалённый Git-репозиторий и заменить `REPLACE_WITH_GITOPS_REPO_URL` в bootstrap-шаблоне.
2. Установить Argo CD.
3. Подключить репозиторий к Argo CD.
4. Сначала синхронизировать Helm-приложения инфраструктурных контроллеров.
5. Затем синхронизировать их конфигурацию и прикладные Applications.
6. Первую синхронизацию выполнять без автоматического prune.

## Важные ограничения текущего этапа

- открытые пароли намеренно не перенесены;
- существующие `app-secrets`, `postgre-secret` и `ghcr-secret` пока должны оставаться в кластере;
- перед полноценным восстановлением с нуля секреты нужно перенести на SOPS + age;
- версии прикладных образов зафиксированы текущими commit SHA, но MinIO пока использует `latest` и требует отдельной фиксации версии.
